# Вкусно дома · Telegram Mini App

Бот на **aiogram 3** и Mini App для планирования семейного питания. Солнечно-жёлтый интерфейс с коралловыми акцентами, фотографиями еды, пошаговой анкетой, меню по дням, порциями для каждого человека, раскрывающимися рецептами и списком покупок с галочками.

Расчёты калорий, домашних запасов, целых упаковок и бюджета выполняются в Python. Сохранились опрос в чате, индивидуальные ограничения, уточнения для малышей и замена блюд. Чат и Mini App используют одну SQLite-базу.

## Тарифы

- Для одного человека меню бесплатно.
- Для двух и более членов семьи нужен семейный доступ. Рекламная цена — **299 ₽ в месяц**.
- Внутри Telegram цифровая подписка оплачивается **Telegram Stars (XTR)**. Подписка действует 30 дней и автоматически продлевается. Перед оплатой показана сумма в Stars.
- Владелец задаёт фактическую цену через `FAMILY_PRICE_STARS`. Стоимость Stars в рублях зависит от способа покупки, фиксированного соответствия 299 ₽ нет. При значении `0` кнопка оплаты отключена.
- Доступ проверяется сервером перед генерацией и чтением семейного меню. Доступ открывается после события успешного платежа от Telegram. Повторная доставка одного платежа учитывается один раз.
- В приложении можно отключить автопродление. Оплаченный период продолжает действовать. Возврат через Telegram Bot API обрабатывается по событию `refunded_payment`.
- Бесплатность относится к пользователю. Расходы OpenAI API, сервера и комиссии Telegram несёт владелец.

## Запуск

Нужны Python 3.10+, токен бота от [BotFather](https://t.me/BotFather), OpenAI API key и домен с HTTPS для Mini App.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`. Файл содержит секреты и исключён из Git. Как минимум задайте `TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY`, `WEBAPP_URL` и свой `SUPPORT_CONTACT`. Для семейных платежей задайте согласованную вами цену в `FAMILY_PRICE_STARS`. Затем загрузите переменные и запустите процесс.

```bash
set -a
source .env
set +a
python bot.py
```

Один процесс запускает aiogram long polling и aiohttp на порту `8090`. Направьте публичный HTTPS-домен через reverse proxy на этот порт. Mini App и API обслуживаются с одного домена. Не запускайте несколько процессов с одним токеном. Для постоянной работы используйте менеджер процессов на вашем сервере.

В BotFather настройте Main Mini App для вашего бота, указав тот же `WEBAPP_URL`. При запуске бот сам устанавливает кнопку меню и присылает кнопку открытия Mini App по команде `/start`. Бот работает в личных чатах.

Для обновления старой версии сохраните SQLite. Если `family-menu.sqlite3` лежит в корне проекта и `BOT_DB` не задан, приложение автоматически использует прежний файл. Иначе укажите его путь в `BOT_DB`. Таблицы подписок добавляются автоматически.

## Предпросмотр дизайна

```bash
source .venv/bin/activate
python preview.py
```

Откройте `http://localhost:8090`. Доступны главная, пример меню с рецептами, пример списка покупок и экран тарифов. Предпросмотр помечен как демонстрационный. Для личной анкеты откройте приложение через Telegram после запуска `bot.py`.

## Команды и данные

`/app` открывает Mini App, `/menu` продолжает анкету в чате, `/new` заменяет анкету, `/delete` удаляет анкету и меню. `/paysupport` показывает контакт для вопросов оплаты и возврата.

API проверяет подпись Telegram `initData` и её возраст, а ID пользователя получает из подписанных данных. Клиентские признаки оплаты не открывают доступ. Анкеты хранятся в SQLite и отправляются OpenAI для генерации. Удаление анкеты сохраняет платёжные записи и подписку. Отменять автопродление нужно отдельно.

Цены продуктов, калорийность и выход блюд ориентировочные. Каталоги и наличие магазинов не подключены. При аллергии семья проверяет маркировку каждой упаковки. Режим кормления и подходящие текстуры малышей задаёт семья.
