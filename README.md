# Семейное меню · Telegram-бот

Бот проводит анкету на русском и присылает семейное меню по дням, порции и калорийность для каждого человека, рецепты, корзину по магазинам и итог по бюджету. Анкета и последний план сохраняются в SQLite. Можно выбрать 3 дня, 7 дней, месяц, остаток месяца или свой срок от 1 до 31 дня.

## Запуск

Понадобится Python 3.10 или новее с системной базой часовых поясов. На Linux и macOS дополнительные пакеты обычно не нужны. Если Python не находит часовой пояс (например, в Windows), выполните `py -m pip install tzdata` перед запуском.

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot` и получите токен нового бота.
2. Создайте [ключ OpenAI API](https://platform.openai.com/api-keys) в проекте с доступом к модели `gpt-4.1-mini`. Генерация оплачивается по тарифам API.
3. Распакуйте архив, откройте папку `family-menu-bot` в терминале и выполните команды ниже. Секреты вводятся без отображения на экране.

```bash
read -rsp 'Telegram Bot Token: ' TELEGRAM_BOT_TOKEN; echo
read -rsp 'OpenAI API Key: ' OPENAI_API_KEY; echo
export TELEGRAM_BOT_TOKEN OPENAI_API_KEY
python3 bot.py
```

Команды выше рассчитаны на Bash. В PowerShell запустите `$env:TELEGRAM_BOT_TOKEN = Read-Host 'Telegram Bot Token' -MaskInput`, `$env:OPENAI_API_KEY = Read-Host 'OpenAI API Key' -MaskInput` и `py bot.py` (PowerShell 7.2+).

4. Откройте своего бота в Telegram и отправьте `/start`. Для постоянной работы запустите процесс на компьютере или сервере, который будет оставаться включённым. На один токен запускайте один процесс.

По умолчанию используется часовой пояс `Europe/Moscow`. Для другого региона задайте `BOT_TZ` (например, `Asia/Yekaterinburg`). `BOT_DB` задаёт путь к SQLite, по умолчанию это `family-menu.sqlite3` в рабочей папке. `OPENAI_MODEL` позволяет выбрать другую модель Chat Completions с поддержкой JSON mode.

## Как пользоваться

- `/start` открывает или продолжает опрос. Если уже есть готовое меню, бот покажет его.
- В магазинах можно нажимать несколько кнопок, а затем «Готово». Номера и названия также принимаются текстом.
- «Бюджет теперь 24 000 ₽ в месяц» исправит ответ. «Замени обед второго дня на блюдо без рыбы» обновит план и список покупок.
- `/menu` повторно показывает меню. Если расчёт прервался после анкеты, команда запускает его снова.
- `/new` начинает новую анкету, заменяя прежнюю. `/delete` удаляет анкету и меню из базы бота. Эти команды не удаляют сообщения в Telegram.

## Источники данных

Цены, калорийность продуктов и вес готовых порций ориентировочные. Бот не подключён к местным каталогам магазинов и не проверяет наличие, скидки или этикетки. При аллергии рекомендации по покупкам требуют сверки состава и следов на конкретной упаковке. Для маленьких детей бот использует указанные семьёй продукты и режим кормления. Правила анкеты и данные от пользователя передаются через OpenAI API для обработки. Файл базы содержит ответы семей и должен храниться с ограниченным доступом.

Расчёт выполняется в Python. Калорийность — сумма по ингредиентам (`г × ккал на 100 г / 100`). Корзина учитывает долю съедобной части, домашние запасы и округление до целых упаковок после объединения потребности на весь срок.
